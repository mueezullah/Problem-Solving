## 🚀 How to Use

1. **Clone the repository**:

   ```bash
   git clone https://github.com/mueezullah/Problem-Solving.git
   cd Problem-Solving/DSA-C++
   ```

2. **Navigate to the topic of interest**:
   Change into the specific directory like `Arrays` or `Binary Search`.

   ```bash
   cd "Binary Search"
   ```

3. **Learn the Approach**:
   Open the target `.cpp` file in any code editor to review the structured comments regarding the approach and complexity _before_ diving into the code.

4. **Compile & Run locally**:
   You can easily run any solution using `g++`:
   ```bash
   g++ 01-BinarySearch.cpp -o solution
   ./solution
   ```
